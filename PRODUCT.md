# Product

Brain Companion is a personal second brain for one owner and their authorized agents. The project follows actual personal use cases and provides a self-hostable public example; it has no multi-user signup or billing.

Agents supply final Markdown and source verification. Jev provides optional advice. The service enforces authorization, privacy routing, revision checks, exact retries, and recorded operations. The browser explores notes, links, sources, and changes, and provides explicit review and bounded undo actions. Obsidian remains a compatible editor.

- Preserve the single-owner model and portable Markdown.
- Keep public demonstrations clearly synthetic.
- Explain pending, applied, unavailable, and synced states accurately.
- Show source evidence and actual changes before review actions.
- Keep setup independent of the maintainer's machine and accounts.

The visual system is documented in [DESIGN.md](DESIGN.md). The implemented workflow is [docs/agent-guide.md](docs/agent-guide.md).
